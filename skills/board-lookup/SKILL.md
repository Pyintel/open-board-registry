# Dev Board Spec Lookup

Use `module_query_knowledge` or `hw_board_registry` to search for dev board specifications matching `$ARGUMENTS`.

Retrieve and summarize:
- Board Name & Vendor
- MCU & CPU Architecture
- Clock Speed (FCPU), RAM, and Flash/ROM limits
- Operating Voltage
- Connectivity & Onboard Peripherals (screens, sensors, LEDs)
