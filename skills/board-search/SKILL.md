# Dev Board Feature Search

Use `module_query_knowledge` to search the board database for microcontrollers matching `$ARGUMENTS` (e.g., "ESP32 with screen", "nRF52840 Bluetooth", "Cortex M4").

Format the matching boards in a table displaying:
1. Board Name & Vendor
2. MCU & CPU Architecture
3. RAM & Flash capacity
4. Onboard Peripherals & Interfaces
